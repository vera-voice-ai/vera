# Карта в iPhone-приложении Веры · дорожная карта

Сейчас (v0.3, 2026-11-24): вкладка «Карта» — Google Navigation SDK внутри приложения (ключ владельца в связке ключей
телефона), поиск места — MapKit Apple, маршрут и ведение — Google в режиме «авто» (мотоцикла в iOS SDK нет). Hermes
управляет навигатором инструментами `phone_route`, `phone_route_status`, `phone_route_stop` (плагин vera-phone), на
схеме Мака — плитка iPhone со строкой «карта».

Правило для всего ниже: история и места владельца — его данные. Хранятся у Веры (телефон и
`~/Library/Application Support/Vera03`), наружу не уходят; что можно сделать на телефоне — делается на телефоне.

## 1. Довести основу (без данных Google)

- **Проверка в езде**: ведение с погашенным экраном, перестроение, «приехали»; что видно на экране блокировки.
- **Звук**: выбор «подсказки голосом Google / только звук / голосом Веры» (тексты манёвров у SDK есть).
  Приглушать музыку на манёврах не будем — по решению владельца.
- **Настройки маршрута**: без платных дорог и паромов, без магистралей (`avoidsTolls`, `avoidsFerries`,
  `avoidsHighways`) — переключатели на карте и параметры у `phone_route`.
- **Свои места**: «дом», «работа», избранное — список Веры на телефоне; Hermes знает их по имени («поехали домой»).
- **Своя история поездок**: с этого дня телефон сам пишет поездки (куда, когда, сколько ехали, трек) и отдаёт Вере
  на Мак. Это и есть надёжная «история» — без зависимости от экспорта Google.

## 2. Hermes умнее в дороге

- Промежуточные точки (до 25 в SDK): «через заправку», «заскочим в магазин по пути».
- «Сколько ехать / где поворот» голосом — уже есть инструмент, нужен короткий разговорный ответ на телефоне.
- Встречи из календаря Google → «поехали на встречу» (у Hermes Веры уже есть доступ к Google Workspace).
- «Напиши жене, когда буду» — время приезда из навигатора; отправка сообщения — только с «да» владельца.

## 3. Данные Google-аккаунта

Что реально можно взять (проверено 2026-11-24):

| Данные | Как достать | Ограничения |
|---|---|---|
| Избранные / сохранённые места | Google Takeout («Сохранённое», «Ваши места» — GeoJSON/CSV) → импорт в Веру | Разовый импорт, не синхронизация. У Data Portability API есть scope `dataportability.maps.starred_places` (Restricted), но доступность по странам не подтверждена — проверить для аккаунта владельца |
| Хронология (Timeline) | С 2024 года живёт только на телефоне, веб-версии нет. Экспорт: Google Maps на iPhone → Настройки → Личный контент → «Экспортировать хронологию» → файл → импорт в Веру | Нет API для постоянной синхронизации; экспорт на iPhone, по отзывам, бывает неполным; формат JSON менялся |
| Адреса встреч, контактов | Календарь и Контакты через Google-доступ Hermes | Только то, что есть в событиях и карточках |
| «Дом», «Работа», недавние поиски | — | API нет; заводим свои места (п. 1) |

Импорт: файл из Takeout или экспорт хронологии кладётся в «Файлы» → Вера разбирает его на телефоне → места на
карте, частые места, статистика поездок; Hermes получает сводку (не сырые координаты), когда спрашивают.

## 4. Свой слой на карте

- Метки своих мест и импортированного избранного на карте навигатора.
- История: где бывал, тепловая карта, километры за неделю/месяц, «последний раз здесь был …».
- На схеме Мака — строка поездки в плитке iPhone (уже есть фаза и остаток пути).

## Не делаем / под вопросом

- Свой пошаговый навигатор поверх Directions/Routes API — правила Google это запрещают, для ведения есть только
  Navigation SDK.
- Офлайн-карты: Navigation SDK без сети маршрут не строит; если понадобится — отдельный разговор (своё ведение на
  данных OpenStreetMap).
