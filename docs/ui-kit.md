# UI-кит Веры (VeraKit)

Общие детали интерфейса Веры — для Мака и телефона. Это библиотека `app/Sources/VeraKit` (продукт `VeraKit` в
`app/Package.swift`, macOS и iOS), а в самом приложении — окно **«UI-кит Веры»**: капсула «UI-КИТ» в шапке рядом с
`VERA v0.3 · Based on HermesAgent`. В окне каждая деталь нарисована в своих состояниях на образцовом тексте, без
Hermes и микрофона.

## Что внутри

| Слой | Где | Что |
|---|---|---|
| Цвета | `Theme` | фон, заливка контура, цвет владельца (`vera` — наше, `hermes` — подключённое), цвета доменов, `ok/warn/bad`; `Theme.palette` — все по порядку с назначением |
| Формы | `Theme` | `ourDash` `[6, 4]`, радиусы: `contourRadius` 13, `partRadius` 14, `cardRadius` 10; текст: `textPrimary/Secondary/Faint` |
| Шрифты | `VeraType`, `.veraType(_:)` | ступени: `title` 16 rounded, `heading` 11 rounded bold, `body` 12, `caption` 10, `figure` 15 mono, `data` 9 mono, `label` 8 mono bold |
| Рамки | `.partFrame(color, dashed:)` | плитка схемы: пунктир — наш модуль, сплошная — подключённый код |
| Плитки | `Plate`, `ModuleContour`, `InnerCard` | плитка части на схеме; контур модуля с точкой домена и ярлыком; карточка внутри |
| Метки, кнопки | `Pill`, `OriginBadge`, `CapsuleButton`, `SectionLabel` | капсулы шапки; «чьё» (НАШЕ / HERMES / НАШ ПЛАГИН В HERMES); единственная нажимаемая вещь на плитке |
| Данные | `Stat`, `KeyValue`, `EmptyNote`, `Format`, `linkified` | цифра с подписью, строка «ключ · значение», пустое состояние, форматы мс/счётчиков/времени |
| Сфера | `ParticleSphere(speaking:voiceEnergy:particles:)` | сфера частиц Веры из Vera Sphere Lab (Metal, 20 тыс. на большой сцене, ~5 тыс. в плитке): покой и из режимов стенда только «говорит» (розовеет, складки на пиках настоящего голоса); в офлайн-снимке — те же частицы на Canvas (`ParticleSphere.offscreen`). Сейчас — в плитке «Ответ · голос» на Маке, дальше — iPhone и простой экран разговора |
| Служебное | `MaybeScroll` | прокрутка, которую умеет нарисовать офлайн-снимок |

## Правила

- Новый цвет, ступень шрифта или повторяющаяся деталь — в VeraKit, и строка в `KitView` (окно кита). Не в панель.
- Деталь, которая нужна только одной плитке, остаётся в своём файле в `app/Sources/Vera`.
- Размеры шрифтов берутся из `VeraType`. Старые `.font(.system(size: …))` в панелях переводятся на шкалу по ходу правок,
  без изменения вида (сверка снимками «до» и «после»).
- Проверка: `.build/debug/Vera --mute --snapshot "$TMPDIR/vera.png" --snapshot-kit "$TMPDIR/kit.png"` — смотри оба PNG.
- Телефон (`phone/`) подключает продукт `VeraKit` из пакета `app` так же, как `PhoneWire`; своя палитра и плитки
  телефона переезжают на кит.
