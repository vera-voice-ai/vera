# Вера 0.3 · правила для агентов

Вера 0.3 — нативное macOS-приложение (SwiftUI), которое визуализирует работу Hermes Agent
и через плагины Hermes добавляет наш функционал. Стиль и правила работы — из Веры 2.

## Что где

- iPhone-приложение — устройство и решения (сборка, бесплатный аккаунт, доставка, мост к Hermes, навигатор, музыка,
  журнал активности, Live Activity, работа нескольких сессий): [`docs/phone.md`](docs/phone.md). Прочитай перед правкой телефона.

## Главные правила

- **Мозг один — Hermes. Вера — только обвязка.** Вера сама не думает и не вызывает модели: никакого «быстрого мозга»,
  своего агентного цикла, локальной LLM, арбитра внимания с моделью. Всё, что решает, планирует и отвечает, делает Hermes.
  Наше — окна, голос (уши и рот: распознавание и озвучка, без смысла), адаптер (транспорт к шлюзу), пульс (наблюдение),
  плагины Hermes, сборка и обновление. Механика без интеллекта допустима и должна быть явной: конец фразы по тишине,
  перебивание, «да/нет» голосом на открытый вопрос о разрешении. Что-то из Веры 2 (уши, «кто говорит», сцена)
  переносится только как обвязка: факты и контекст для хода Hermes, а не решения.
- **Вера — это само приложение.** Внутри нет отдельной сущности «Вера»: основная сессия — «Разговор», части — по
  своей роли (Голос, Адаптер, Пульс…). Не называть «Верой» панели, окна и сессии.
- **Границы на схеме:** сплошная — подключённый код (Hermes и его части, провайдер, стандартные плагины),
  пунктир — наш написанный модуль (Разговор, Уши, Голос, Адаптер, Пульс с «Ходом», плагины vera-*). Цвета — по-прежнему по домену.
- **Одна вкладка — схема.** Всё показывается на ней; новое — внутри своей части, не отдельной страницей.
- **Настройка — там, где живёт настраиваемое.** Настройки Hermes (провайдер, ключ, модель) живут в Hermes; Вера —
  только окно к ним через шлюз и vera-setup, своего слоя настроек поверх Hermes не держит. Кнопки — на плитках:
  «⚙ провайдер и ключ» у провайдера, «↻ перезапустить» у шлюза; наши настройки (голос) — на «Ушах» и «Голосе».
- **Без правой панели и кликабельных плиток.** Всё на схеме; нажимаются
  только явные кнопки.
- **Hermes — цельная плитка.** На схемах и доске Hermes один блок, без разбора на органы; его части (шлюз, мозг,
  руки, навыки, память, плагины, платформы, cron, MCP) показываются внутри плитки и берутся вживую из шлюза.

- **Каждая версия Веры — коробка без зависимостей**, если с владельцем явно не договорились об обратном. Всё, без чего
  Вера не работает — Hermes, Python, модели распознавания и голоса, рабочие процессы, — лежит внутри `.app`, а версии
  записаны в замок. Нельзя опираться на установленное у пользователя (Python, Homebrew, папки других Вер) и на
  включённые системные службы (Siri и Диктовка, облачные сервисы Apple). Допустимы только API самой macOS, которые
  работают без настройки и сети (микрофон, звук, синтез речи). Новая зависимость вне коробки — только после
  разговора с владельцем, и её нужно записать сюда как исключение.
  Исключения: **туннель владельца** (например, `cloudflared` на его Маке: `<свой адрес> → 127.0.0.1:8765`; адрес — `phone_tunnel` в
  `local.json` данных Веры и `VERA_TUNNEL_HOST` в `phone/Local.xcconfig`) — дорога
  iPhone-сенсора к Вере вне дома; Вера его не везёт и без него работает, сама слушает только loopback.
  **Google Maps на телефоне** (Navigation SDK в приложении, проект Google Cloud владельца; без ключа — MapKit и внешняя ссылка) — по просьбе
  владельца; без сети карты нет, остальное приложение работает.
- **Вера самодостаточна.** Hermes — пакет внутри `Vera03.app` (stable-тег, официальный `pm bundle`), данные —
  `~/Library/Application Support/Vera03`. См. [`docs/hermes-updates.md`](docs/hermes-updates.md).
  Любая команда Hermes — только с окружением `HermesRuntime.environment` (или `scripts/vhermes` для отладки):
  своё `HOME`, `HERMES_HOME`, минимальный `PATH`, **никаких унаследованных переменных**. Голый `hermes` — владельца.
- **Ничего не искать на машине.** Никаких поисков по PATH, Homebrew, `~/.local/bin`, чужим папкам — ни в коде
  Веры, ни в скриптах. Все пути — из бандла или из папки данных Веры.
- **`~/.hermes`, `~/.local/bin/hermes` и launchd-шлюз владельца не трогаем вообще** — ни чтение конфигов,
  ни команды, ни плагины. Только как справка по коду, если нужна.
- **Полный `setup-hermes.sh` не запускать** — он публикует лаунчеры в `~/.local/bin` и правит `.zshrc`.
  Пакет собирает только `scripts/build-hermes.sh` (сборочная копия `~/.vera03/hermes`, `--runtime-only`).
- **Ядро Hermes не правим.** Наш функционал — плагины и скиллы из этого репозитория. Если плагину не хватает
  возможностей ядра — запиши это как вопрос. `hermes update` не используем: версию меняют
  `scripts/build-hermes.sh <тег>` + `scripts/bundle.sh` по процедуре.
- **Ключи модели вводит владелец** в карточке «⚙ настроить» у провайдера (и токен бота — в «⚙ подключить» у Telegram, ключ Google Maps — в «Настройки → Карта Google» на телефоне); агенты не вводят ключи и не читают
  `~/Library/Application Support/Vera03/hermes/.env`.
- **Секреты.** Тикет шлюза (`ticket`, подпротокол `hermes-gateway-ticket.*`) — секрет: не логировать,
  не печатать, не сохранять.
- **Плагины Веры** — `hermes-plugin/<имя>`: `vera-pulse` (наблюдатель), `vera-setup` (RPC: модель по умолчанию, токен бота Telegram — только запись, без чтения значения)
  и `vera-ears` (распознаватель `gigaam` для голосовых сообщений Hermes: `stt.provider: gigaam`, зовёт `Vera --transcribe`),
  `vera-phone` (инструменты `phone_route`, `phone_route_status`, `phone_route_stop` — навигатор iPhone, `phone_music_play`,
  `phone_music_control`, `phone_music_status` — его плеер; транспорт — файлы
  `<данные Веры>/phone-bridge/`, Вера передаёт их телефону; путь — `VERA_DATA` в окружении шлюза) и `vera-context`
  (раздел системного промпта: карта трёх каналов — «Вера» на MacBook, «iPhone», Telegram — и подробности своего; канал —
  по `client` в `session.create` (`vera-mac`/`vera-phone`), файлам закреплённых сессий или платформе; старым сессиям —
  один раз через `pre_llm_call`), `vera-browser` (инструмент `mac_browser` — окно «Браузер Веры» на Маке: свой профиль и
  тема, порт DevTools 9333 на loopback; Hermes работает в нём через `browser.cdp_url`, а хук `pre_tool_call` открывает окно,
  если браузерный инструмент зовут при закрытом; капчу и последнюю кнопку жмёт владелец). `vera-context` доносит
  изменившийся текст до старых сессий один раз (дайджест в `vera-context-seen.json`).
  Новый плагин — добавить имя в `HermesRuntime.pluginNames` и `hermes.lock.json` (`plugins`).
- **Плагин vera-pulse только наблюдает.** Хуки возвращают `None`; в журнал — имена, id, длительности,
  статусы, счётчики. Никаких аргументов инструментов, текстов сообщений и ответов модели.
- **Вопросы агента.** Вера отвечает только на `approval` и `clarify` (`GatewayClient.answerable`); новый тип —
  только вместе с карточкой в чате. `secret`/`sudo`/хранилище паролей Вера не принимает никогда.
- **Причина, а не симптом.** Ищи решение или контракт, который дал сбой, и чини его.
  Не добавлять списки фраз, повторы с подсказкой и прочие заплатки. Не ослаблять проверку, чтобы она прошла.
- **Модели и платные вызовы.** Тесты по умолчанию без сети и без вызовов моделей.
- **Обновление контракта.** Поменял то, на что Вера опирается в Hermes (метод шлюза, хук, путь) —
  обнови `hermes.lock.json` (`contract_paths`, `hooks_used`) и `docs/hermes-updates.md`.

## Стиль интерфейса (как в Вере 2)

- **UI-кит — `app/Sources/VeraKit`** ([`docs/ui-kit.md`](docs/ui-kit.md)): цвета, шкала шрифтов `VeraType`, рамки,
  плитки, метки — общие для Мака и телефона. Новое общее — туда и строкой в окно «UI-кит Веры» (`KitView`).
  Это окно — единственное исключение из «одна вкладка — схема»: справочник деталей, не данные.
- Фон `rgb(0.035, 0.025, 0.047)`, контур модуля: заливка `rgb(0.065, 0.05, 0.08)`, радиус 13,
  пунктир `[6, 4]` цветом домена с прозрачностью 0.68, точка домена 8 pt, заголовок 16 pt rounded semibold,
  рядом моно-ярлык 8 pt (`hermes/gateway`).
- Подписи и цифры — моноширинный шрифт 8–10 pt, белый с прозрачностью 0.45–0.7.
- **Цвет владельца:** всё наше (Вера) — розовое `Theme.vera` (как акцент Веры 2), Hermes — жёлто-оранжевый `Theme.hermes`;
  внутри частей — цвета доменов. Цвета доменов — в `app/Sources/VeraKit/Theme.swift`. Новые цвета добавлять туда, не в панели.
- Акцент шапки — розовый `rgb(0.94, 0.13, 0.61)`, кнопки-капсулы с обводкой.

## Сборка и проверка экрана

- `scripts/check.sh` — все офлайн-проверки разом: Swift-тесты, тесты каждого плагина, синтаксис скриптов, замок.
  Запускай перед каждым коммитом.
- `cd app && swift build` — сборка; `swift test` — тесты (без сети).
- `scripts/build-hermes.sh` — пакет Hermes, `scripts/build-ears.sh` — уши (оба нужны один раз и при смене версии); `scripts/bundle.sh release` (если поменялся только код Веры — быстрый путь ~30 с, подмена исполняемого файла; `VERA_FULL=1` — полная пересборка) —
  самодостаточный `Vera03.app`; `scripts/run.sh` — собрать и открыть.
- **Снимок без окна:** `.build/debug/Vera --snapshot <файл.png> [--mute]` рисует доску в PNG и выходит.
  С `--mute` Вера не подключается к Hermes и не читает пульс (только каркас). Без `--mute` — поднимет свой шлюз
  (первый старт до ~30 с, `--wait 40`) и подождёт живых данных. `--snapshot-setup <файл.png>` — ещё и
  карточка «⚙ настроить» провайдера, `--snapshot-kit <файл.png>` — окно UI-кита, `--snapshot-flows` — по точке на каждой линии (только проверка рисования).
- **Доска показывает только настоящие потоки и живые данные.** Не добавлять имитацию трафика, «демо-точки» и
  пояснительные надписи вместо данных: в плитке — то, что сейчас происходит или лежит на диске. Текстовые поля в офлайн-снимке рисуются жёлтыми плашками — это ограничение ImageRenderer. Так проверяй любое изменение экрана; не проси у владельца скриншоты.
- Внутри снимка `ScrollView` не рисуется — оборачивай прокрутку в `MaybeScroll(scrollable:)`.

## Вопросы к ядру Hermes

Чего не хватает плагинам и Вере в ядре Hermes (ядро не правим — ждём или предлагаем апстриму):

- **Факт о говорящем отдельно от текста.** `prompt.submit` не принимает поле «кто говорит»; `voice_context`
  работает только в режиме `voice-live`. Пока Вера ставит пометку в начало фразы (`[голос не узнан]`,
  `[говорит: имя]`) и только когда говоришь не ты (`SpeakerNote`). Нужен параметр хода (метаданные реплики),
  который Hermes кладёт в контекст модели, не смешивая с текстом пользователя.

## Git

- Одна законченная задача — один коммит. Без пуша без слова владельца. Секретов в коммитах нет.
