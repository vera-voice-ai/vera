# Умный анализатор

Отдельное приложение macOS для сравнения задержки текстовых запросов с локальной озвучкой. Из корня Vera 2 запусти `./smart-analyzer/run.sh` из оболочки с экспортированными ключами.

| Провайдер | Авторизация |
| --- | --- |
| DeepSeek API | `DEEPSEEK_API_KEY` или `DEEPSEEK_KEY` |
| OpenCode Go | `OPENCODE_GO_API_KEY` или `OPENCODE_API_KEY` |
| Claude | Вход в официальный Claude Code по подписке через `claude auth login` |
| OpenAI | Вход в Codex через `codex login` с аккаунтом ChatGPT |

«Пинг» отправляет короткий запрос без содержимого поля «Контекст». «Отправить» добавляет введённый или загруженный UTF-8 контекст целиком. Лимиты входа определяет выбранная модель. Измерения относятся к приложению: первый видимый текст, начало локальной озвучки и конец запроса. Codex CLI может вернуть текст только после завершения сообщения агента. Ключи читаются из окружения, а запросы отправляются выбранному провайдеру по нажатию кнопки.

Для замера из терминала запусти `./smart-analyzer/run.sh --ping opencode --model hy4-flash-free --voice`. Другие значения `--ping`: `deepseek`, `claude`, `openai`. `--model` переопределяет модель, `--voice` включает озвучку. Результат выводится как JSON с задержками в миллисекундах.
